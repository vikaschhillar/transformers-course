# Hugging Face LLM Course

My workspace for https://huggingface.co/learn/llm-course (setup from Chapter 0).

## Activate the environment

    cd ~/Desktop/transformers-course
    source .env/bin/activate

Run `deactivate` to leave it.

## Check the setup

    python test_setup.py

## Installed
- Python 3.11 virtual environment in `.env/`
- `transformers[sentencepiece]`
- `torch`
